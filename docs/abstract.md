## Apstrakt (Srpski)

U radu je predstavljen Adventure DSL, deklarativni domenski specifičan jezik namenjen kreiranju tekstualnih avantura i interaktivne fikcije. Razvijen je kompletan prevodilački sistem koji obuhvata leksičku analizu, rekurzivni silazni parser sa apstraktnim sintaksnim stablom i semantičku analizu sa statičkom proverom tipova. Generička faza podržava dva pristupa: direktno interpretiranje u konzolnom okruženju i generisanje samostalnih web aplikacija u formatu HTML5 i JavaScript. Rešenje je uspešno evaluirano na deset reprezentativnih scenarija i pokriveno automatizovanim testovima, čime se dokazuje jednostavnost pisanja interaktivnih priča uz očuvanje potpune tipovske i semantičke sigurnosti.


---

## Abstract (English)

This paper presents Adventure DSL, a declarative domain-specific language designed for creating text-based adventures and interactive fiction. A complete compilation system was developed, encompassing lexical analysis, a recursive descent parser with an abstract syntax tree, and semantic analysis with static type checking. The generic phase supports two approaches: direct interpretation within a console environment and transpilation into standalone HTML5 and JavaScript web applications. The solution was successfully evaluated on ten representative story scenarios and verified by automated unit tests, demonstrating the simplicity of authoring interactive stories while preserving strict type and semantic safety.
